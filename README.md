# agent-office

Офис агентов: проект объявляет **манифест** (роды узлов, переходы, порождения, роли, запросы человеку), офис его применяет
поверх append-only журнала фактов. Человек — узел контура: вбрасывает заявки и отвечает на запросы в дашборде.

```
npm install
npm test                              # сценарии петли: заглушка-исполнитель, ручные часы
npm start -- examples/toy --fake      # офис на заглушках, без моделей и денег → http://127.0.0.1:4700
npm start -- <каталог проекта>        # живые агенты (claude CLI); состояние — в <проект>/.office/
npm run dev                           # дашборда на http://localhost:4701 (проксирует /api в офис)
npm run lint                          # eslint: отступ 4, фигурные скобки всегда и с новой строки (lint:fix — поправить)
npm run schema                        # пересобрать схему манифеста из типов
npm run bundle                        # офис одним файлом → dist/agent-office.js
npm publish                           # проверки → бандл → реестр (хуки prepublishOnly и prepack); версия — в корневом package.json
npm version patch && git push --follow-tags   # выпуск: тег vX.Y.Z запускает .github/workflows/release.yml → npm
```

## Установка

```
npm install -g @tihonove/agent-office
agent-office <каталог проекта> [--fake] [--port 4700] [--tick 2000]
```

В пакете один js-файл: офис со всеми зависимостями и вшитой дашбордой (`scripts/bundle.ts`). Нужен Node 24+.

**Поставить офис в свой проект** — [`docs/`](docs/README.md): предусловия, словарь, справочник манифеста, промпты ролей,
порядок настройки, готовые схемы и частые ошибки. Документация и схема манифеста едут в пакете
(`$(npm root -g)/@tihonove/agent-office/docs/`).

## Конституция (проекту не отдаётся)

1. Журнал append-only; состояние — производное, пересчитывается из фактов.
2. Ключ (роль, узел) уникален; повторный запуск — продолжение, а не второй агент.
3. Проекция только на чтение; наружу агент ходит только через примитивы.
4. Агент не меняет состояние — он публикует; переходы применяет офис.
5. Предикаты и условия переходов — чистые функции от снимка мира.
6. У каждого обращения к человеку есть дедлайн и объявленный исход по молчанию.

## Агент

Живёт один заход: поработал, опубликовал, умер. Ожидание живёт в мире: спросил человека — умер, пришёл ответ — офис поднял
тот же ключ с ответом в `повод.md`. Вход и выход — каталог назначения `<проект>/.office/назначения/<роль>/<узел>/`:

```
повод.md        почему подняли именно сейчас + памятка, как говорить с офисом
проекция/       только чтение: узел.md, области.md, артефакты/…
out/            пишет агент: артефакт-*.md, результат.md, вопрос.md, флаг-*.md, дотянуть.md
транскрипт.jsonl
```

Файлы в `out/` — сегодняшний транспорт. Ядро знает только `Reception.accept(key, call)`; MCP-сервер станет ещё одним модулем
контейнера, зовущим тот же `accept`.

Офис **не знает про git и worktree**: claude стартует в корне проекта, а где и как работать с кодом, говорит промпт роли
(и сквозные `args` исполнителя в манифесте).

## Офис для самого себя

В корне лежит наш собственный манифест — `office.yaml` с промптами в `office/roles/`: agent-office разрабатывается офисом.

```
npm run office                        # собрать дашборду из исходников и поднять офис на этом репозитории
                                      # → http://127.0.0.1:4700 (живые агенты claude); не собралась — офис не встаёт
npm run stand -- list                 # какие стенды сейчас подняты
```

Роли: **штурман** ведёт заявку по курсу (на входе — в работу / разбить / отказать; после реализации — поднимает стенд;
после приёмки — вливает ветку в ствол), **аналитик** пишет постановку, **реализатор** делает в своём worktree.

Человек в контуре дважды и оба раза обязательно: согласует постановку («что делать будем») и принимает работу
на живом стенде. Стенд — офис из ветки реализатора на свежей копии `examples/toy` (`scripts/stand.ts`, порт 4800 + номер узла).
Любая доработка идёт через аналитика. Молчание человека ничего не запускает и не вливает: заявка откладывается.
Путь заявки нарисован в шапке `office.yaml` и закреплён сценариями `packages/office/test/self.test.ts`.

## Отложено

Аренды и потолки мест, бюджеты и рубильник, многомашинность, подписки и гейты, консультации между ролями, цели с табло,
автозапуск `judge` дешёвым агентом (сейчас вердикт вносится руками из дашборды). Вместо бюджета — предохранитель:
три потери агента подряд → флаг, дальше роль на узле поднимает только человек.
