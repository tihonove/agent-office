# Что нужно заранее

## Для прогона на заглушках (`--fake`)

- **Node 24+** (`node --version`). Офис — один js-файл без зависимостей.
- **Офис:** `npm install -g @tihonove/agent-office` → команда `agent-office`. Без установки: `npx @tihonove/agent-office <проект> --fake`.
- **Свободный порт** 4700 (или любой через `--port`). Дверь слушает только `127.0.0.1`: паролей у неё нет.

Модели, ключи, `claude` и git для `--fake` не нужны.

## Для живых агентов

- **`claude` в `PATH` и уже авторизован.** Офис запускает `claude -p …` без интерфейса: спросить логин или
  разрешение у человека агент не сможет. Проверка: `claude -p 'скажи ок'` отвечает без вопросов.
- **Git-репозиторий**, если роли работают с кодом: офис git не знает, но промпты ролей обычно велят работать в worktree.

## В проекте

- **`.office/` — в `.gitignore`.** Там состояние офиса: журнал `journal.jsonl` и каталоги назначений агентов.
  Он пишется постоянно и в историю проекта не нужен.
- **`.worktrees/` — в `.gitignore`**, если промпты велят агентам заводить worktree внутри проекта (так делают готовые схемы).

```
printf '.office/\n.worktrees/\n' >> .gitignore
```

- `office.yaml`, `office/roles/`, `fake/` — **в git**: это настройка офиса, её правят как код.

## Файлы офиса в проекте

```
<проект>/
  office.yaml              манифест; имя и место фиксированы — корень проекта
  office/roles/*.md        промпты ролей (путь любой: он пишется в манифесте, относительно office.yaml)
  fake/<роль>/*.md         заготовки для --fake; путь фиксирован — <проект>/fake/
  .office/                 состояние офиса (создаётся сам)
```
