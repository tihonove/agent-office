# agent-office в своём проекте

Руководство для того, кто ставит офис в свой проект: пишет манифест `office.yaml`, промпты ролей и заглушки,
проверяет их прогоном `--fake`, поднимает офис с живыми агентами. Читатель — агент (например, `claude` в корне проекта)
или человек. Устройство кода офиса здесь не описано: оно в README репозитория, раздел «Как читать код».

## Где лежит

Документация едет в npm-пакете `@tihonove/agent-office` рядом со схемой манифеста — сеть и клон репозитория не нужны:

```
$(npm root -g)/@tihonove/agent-office/docs/                       # при npm install -g
node_modules/@tihonove/agent-office/docs/                         # при установке в проект
…/@tihonove/agent-office/dist/manifest.schema.json                # JSON-схема office.yaml
```

## Быстрый путь

Задача «поставь офис с аналитиком и реализатором» решается так (подробно — [setup.md](setup.md)):

```
cp -r <docs>/recipes/конвейер/. <проект>/            # office.yaml, office/roles/, fake/
printf '.office/\n.worktrees/\n' >> <проект>/.gitignore
agent-office <проект> --fake                          # → http://127.0.0.1:4700: вбросить заявку, пройти путь
agent-office <проект>                                 # живые агенты
```

Затем подгони промпты `office/roles/*.md` и `args` исполнителей под проект (команды проверки, права).
